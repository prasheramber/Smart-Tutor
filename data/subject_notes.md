# Types of Machine Learning

Machine Learning (ML) is a branch of Artificial Intelligence (AI) that enables computers to learn from data and make decisions or predictions without being explicitly programmed. It identifies patterns from past data and improves its performance through experience. Machine Learning is mainly divided into four types:

1\. Supervised Learning: Supervised Learning is a type of machine learning in which a model is trained using labelled data. Labelled data means the input and its correct output are already provided. The model learns from these examples and predicts the output for new data. For example, a model trained using house sizes and their prices can predict the price of a new house. It is mainly used for classification and regression problems.

2\. Unsupervised Learning: Unsupervised Learning is a type of machine learning in which a model is trained using unlabelled data. It means the data does not contain predefined answers or outputs. The model automatically finds hidden patterns, similarities and groups in the data. For example, a shopping website can group customers based on their shopping habits. It is mainly used for clustering and pattern detection.

3\. Reinforcement Learning: Reinforcement Learning is a type of machine learning in which a model learns by interacting with its environment. It learns through trial and error and receives rewards for correct actions and penalties for incorrect actions. The main goal is to achieve the maximum reward by choosing the best actions. For example, a robot learns to walk by practising different movements and receiving feedback.

4\. Semi-Supervised Learning: Semi-Supervised Learning is a type of machine learning that uses both labelled and unlabelled data. It uses a small amount of labelled data and a large amount of unlabelled data to train the model. This approach reduces the need for manually labelling large amounts of data. For example, a model can identify different types of animals using a few labelled images and many unlabelled images.

5\. Deep Learning: Deep Learning is an advanced type of machine learning that uses artificial neural networks with multiple layers to learn complex patterns from large amounts of data. It works similarly to the human brain and can automatically identify important features. For example, face recognition systems, voice assistants and self-driving cars use deep learning.

Conclusion: Machine Learning helps computers learn from data and improve their performance. The different types of machine learning are used for different purposes, such as prediction, grouping, decision-making and pattern recognition. These technologies are widely used in healthcare, education, banking, robotics and many other fields.
